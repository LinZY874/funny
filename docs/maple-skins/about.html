先看效果，再安装

工具页可以切换浅色与深色主题，并体验 V3 的蓝蜗牛互动：悬停获得提示，点击立即向前冲刺，连续点击可持续助力。预览使用演示内容；要给自己的 DSH 界面换肤，请下载并安装插件。

插件保留原皮肤与 V1、V2、V3 的切换入口。本页以 V3 为默认展示版本。

安装到 DeepSeek Harness

  1. 下载插件包，将其解压为 dsh-maple-skins 目录。
  2. 在自己的 DSH 部署目录中执行下方命令，把示例路径替换为解压目录的绝对路径。
  3. 重启 dsh web，进入“设置 → 冒险岛皮肤 → 冒险岛 V3”，点击应用。
pnpm dsh plugin --profile web add link:/绝对路径/dsh-maple-skins

选择会在刷新页面或重启后保留。想恢复 DSH 的默认外观时，在同一设置中选择“原皮肤”。

三个版本，随时切换

V1 是蜗牛花园，V2 是蘑菇村景，V3 是原版用色与蜗牛冲刺。界面名称与内部标识统一对应为 V1、V2、V3；下载包保留这三个皮肤与恢复原皮肤的入口。
