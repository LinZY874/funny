## 可直接复制的完整提示词

```text
请为 DeepSeek Harness Web GUI 制作可安装的《冒险岛》079 风格皮肤插件 dsh-maple-skins，并提供可以独立打开的中文交互预览。以随附的当前插件源码和素材为参考，目标是重构“冒险岛 V3（原版用色 · 蜗牛冲刺）”的视觉与手感。

一、交付与版本
交付完整插件目录：package.json、cordis.patch.yml、lib/、skins/、必要测试和 README。插件包版本为 1.0.0。保留“原皮肤”与 V1（蜗牛花园）、V2（蘑菇村景）、V3（原版用色 · 蜗牛冲刺）三个主题，目录和内部 ID 统一为 v1、v2、v3，不增添无用内部版本。V1、V2 沿用随附基线作为对照，重点完成 V3；独立预览默认 V3。真实 DSH 中从“设置 → 冒险岛皮肤”选择主题，保留用户选择，并支持恢复原皮肤。README 给出下载解压、在 DSH 部署目录安装和重启后的选择步骤。

二、视觉目标与阅读体验
让界面整体有冒险岛 079 的氛围：奶油天空、草地绿、温暖木色边框、金币色按钮和像素精灵。浅色主题明亮柔和；深色主题是深绿棕夜园，保持文字、代码、链接和边界清楚。覆盖品牌、欢迎空态、侧栏、新会话入口、输入框、用户气泡和助手回复；品牌使用 MapleStory，核心文案为“让枫叶飘进每一次对话”。
V3 不使用整张地图背景，不铺羊皮纸气泡纹理，不放静态道具展示架、飘落枫叶或流云。保留干净的天空／草地底色、底部草地地平线及克制的木纹细节。深色欢迎空态可以有星月与流星。输入框保持一个清楚的容器，不为占位文字再套内框；回复留足内边距和行距，装饰不得挤压正文、遮挡内容或妨碍点击。

三、角色应与界面动作结合
绿蘑菇用于品牌标与欢迎空态，悬停有轻巧弹跳；绿水灵位于助手回复气泡上，以呼吸和悬停小跳作陪伴；金钱镖从用户消息右上方俯冲飞入，再回弹停在消息右上角；红蓝药水放入“新会话”路牌内右下角，悬停路牌时蹦跳。角色要锚定自己的容器，不随着侧栏折叠、消息换行或窗口变化跑位。精灵保持清晰比例，蓝蜗牛不要大过主要角色。

四、V3 蓝蜗牛的核心交互
蓝蜗牛沿底部草缘从右向左水平慢速巡逻，约 150 秒一圈；从视口右侧之外进入，完全离开左侧之后才在画外开始下一圈。画面内位置只向前，不能突然回退、刹停、蓄力等待或上下飘动。
每次点击都从当前位置立即获得向前速度助力。单次额外推进量以约 60 px 为设计目标，速度助力按 450 ms 时间常数指数衰减：初始额外速度约 133.3 px/s，之后逐渐融回基础巡逻速度。450 ms 是衰减时间常数，不是整段动画的固定时长；逐帧积分与低速截断会带来小误差，不把 60 px 写成严格的实测总位移。结束后仍在巡逻，不出现“停一下再继续”。
支持连续点击：每次立即把速度助力重置到满值，不排队、不按累计次数结算；连点持续前进，松手自然回到巡逻。缩小段正在进行时，继续点击只续助力，不重新变大或重启缩小段。
鼠标进入蜗牛时，只提示性放大到 1.12 倍并让壳泛金光。点击本身不再叠加放大；从点击瞬间的精确大小平滑缩回原大小，冲刺结束后即使鼠标还停在上面也保持原大小。冲刺中重新移入不触发放大，移开后再次进入才有新的悬停提示。
位置和形变分开控制：外层只负责水平位移；内层负责缩放、轻微前倾和原地阻尼形变。出手可有短促的横向拉伸、纵向压扁与约 9° 前倾，随后恢复；速度线拖在右侧，金光随助力衰减。可以有极轻的原地收尾形变，但不能变成纵向位移。不要让 CSS hover、CSS 位移动画与 JavaScript 同时争夺同一项状态。

五、素材使用与相对路径
复用随附的真实 079 精灵和贴图，不用表情符号或重新生成的近似角色代替。V3 素材位于插件内 skins/v3/assets/：mush-green.png（绿蘑菇）、slime-green.png（绿水灵）、snail-blue.png（蓝蜗牛）、money-dart.png（金钱镖）、potion-hp.png 与 potion-mp.png（红蓝药水）、grass-edge.png（草边）、vine-tile.png（藤蔓）、tex-wood-faint-light.png 与 tex-wood-faint-dark.png（明暗细木纹）。
skins/v3/ 内放 skin.json、skin.css、patches.css、hooks.mjs、assets/ 和 preview/。CSS 从自身位置使用 url(assets/文件名)，hooks 按宿主传入的 assetBase 组合资源路径；预览页从 skins/v3/ 加载。不要写个人绝对路径、依赖制作机器的目录或运行中的本地服务地址。保留清单里的素材署名：mxd079.dvg.cn（冒险岛 079 小册子）；游戏素材权利归各自权利人，插件代码许可不能被当成游戏素材授权。

六、插件接入与静态预览
按当前 DSH 的插件机制注册 Host 与 Client：Host 提供皮肤清单、选择状态、作用域样式和资源；Client 提供设置中的切换入口、主题恢复、背景与 hooks 生命周期。CSS 只影响当前皮肤；先准备好新样式再切换，按样式种类和完整地址识别链接，清理旧样式与装饰，避免要点两次才能成功或切换后丢样式。刷新后恢复已选择的外观，卸载时清除帧循环、观察器、事件监听与注入节点。
独立预览提供 V1／V2／V3、浅色／深色和欢迎／示例对话切换，默认 V3；可以输入示例消息观察金钱镖和回复装饰，也能点击蓝蜗牛助力。预览使用虚构演示内容，消息只在当前窗口内，不接入用户的真实聊天或模型服务。尊重 prefers-reduced-motion，让减少动态效果设置有相应的静态表现；主要控制可通过键盘操作。

七、回归与验收
完成后自行 review，并用可重复检查验证：单击与连击立即助力；画内位置持续向前；没有停顿、回退和纵向漂移；悬停只放大一次；点击不二次放大；冲刺途中点击不重启缩小段；恢复巡逻后尺寸正确；窗口变化和标签页恢复不产生大跳跃。测试明暗主题、欢迎空态和长消息的可读性，以及 V1→V2→V3→原皮肤的切换、刷新恢复和清理；检查所有素材相对路径可达。
交付源码、可直接预览的页面、安装包与简明安装说明，报告实际运行过的检查和仍存在的限制。保留既有用户数据与运行配置；当前运行中的 DSH 不作为测试场，安装或重启留给用户明确安排的步骤。
```
