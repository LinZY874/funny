BRING IT TO YOUR WORKSPACE

装到自己的
DeepSeek Harness。

包含 V1、V2、V3 三款冒险岛皮肤与原皮肤切换器。
展示默认 V3，安装后也可以自由选择。

查看插件源码 ↗
  1. 下载并解压插件

    将插件包解压为 dsh-maple-skins 文件夹，放在你希望保留的位置。

  2. 在 DSH 的部署目录中安装

    把下面路径替换为解压后文件夹的绝对路径：

    pnpm dsh plugin --profile web add link:/绝对路径/dsh-maple-skins
  3. 重启，再选择 V3

    重启 dsh web，进入「设置 → 冒险岛皮肤」，选择「冒险岛 V3（原版用色 · 蜗牛冲刺）」。
